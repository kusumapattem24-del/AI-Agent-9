# Topic 9 LMS Assessment Document

## Agent Collaboration and Context Passing – Implement a Coordinated Agent Sub-Workflow

## 1. Assessment Overview

This assessment evaluates your ability to design, build, test, validate, and document a hierarchical parent-child AI workflow in n8n using coordinated agent collaboration, context passing, workflow tools, structured outputs, and state management.

## 2. Assessment Objective

Demonstrate the ability to build a parent coordinator agent that invokes a child workflow, exchanges structured data, manages workflow states, and returns standardized responses.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topics 1–8.
- Active n8n instance with LLM credentials.
- GitHub account for submissions.

## 4. Assessment Tasks

- Exercise 1 – Build the Child Specialist Workflow
- Exercise 2 – Configure the Parent AI Coordinator
- Exercise 3 – Configure the Child Workflow Tool
- Exercise 4 – Configure the Structured Output Parser
- Exercise 5 – Configure Parent Agent Logic
- Exercise 6 – Validate Parent-Child Collaboration
- Exercise 7 – Verify Context Passing
- Exercise 8 – Mini Project: Build a Coordinated Agent Sub-Workflow

## 6. Assessment Success Criteria

- Build a reusable child workflow.
- Configure a parent AI Agent.
- Connect child workflow using Execute Workflow Tool.
- Pass structured inputs between workflows.
- Configure Structured Output Parser.
- Implement state-based logic.
- Aggregate child results into final response.
- Demonstrate flagged and verified scenarios.
